# 个人作品管理设计（仅自己可见 / 编辑文案 / 删除）

日期：2026-09-10
状态：已与用户确认，待实现

## 目标

作者需要管理自己发布的作品，本期做三件事：

1. 切换「仅自己可见 / 公开」。
2. 编辑文案（标题 + 简介）。
3. 删除作品。

入口统一放在作品播放页的右侧互动栏（方案 A）：作者在观看某条作品时，顺手就能改这条作品的属性。

非目标（以后再说）：置顶、下载、评论权限、批量管理、换封面/换视频。

## 交互设计

- 作品播放页右侧互动栏在「分享」下方新增「⋯」按钮，仅作者本人可见（移动端 FeedItem、PC 端 PcFeedCard 同位置）。
- 点击后弹出面板（新组件 `PostMorePanel.vue`）：
  - 移动端：底部升起的面板 + 遮罩。
  - PC 端：贴着按钮浮出的菜单卡片。
- 面板内容三项：
  1. 仅自己可见 / 设为公开：切换项，显示当前状态勾选。
  2. 编辑文案：打开弹窗编辑标题（≤100 字）和简介（≤500 字）。
  3. 删除作品：红色文案，二次确认后执行。
- 个人主页网格：私密作品右下角显示锁角标。
- 自己作品流中的私密作品照常播放（否则无法再改回公开）。

## 后端设计

### 数据变更

新增 `db/init/003_m3_post_visibility.sql`：

```sql
ALTER TABLE `post`
    ADD COLUMN `visibility` VARCHAR(10) NOT NULL DEFAULT 'PUBLIC'
    COMMENT 'PUBLIC / PRIVATE' AFTER `status`;
```

- 新增枚举 `PostVisibility { PUBLIC, PRIVATE }`，新建作品默认 PUBLIC。
- `Post`、`PostVO` 增加 `visibility` 字段。

### 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| PUT | `/api/posts/{id}/visibility` | body `{"visibility":"PRIVATE"}`，仅作者；非法值返回业务错误 |
| PUT | `/api/posts/{id}` | body `{"title":"","description":""}`，仅作者；长度校验 100 / 500 |
| DELETE | `/api/posts/{id}` | 复用已有实现（硬删：MinIO 文件 + 行 + 点赞/评论清理） |

### 可见性规则

| 场景 | 规则 |
|---|---|
| 首页信息流（含轮换重播） | 排除 PRIVATE |
| 他人主页作品列表 | 排除 PRIVATE |
| 自己的作品列表 | 全部保留，返回 `visibility` |
| 点赞列表 | 排除他人 PRIVATE 作品 |
| 作品详情 | 非作者访问 PRIVATE 作品 → 404「作品不存在或已删除」 |
| 评论/点赞 | 私密期间不可被他人访问（详情已拦截），既有点赞评论数据保留 |

### 缓存

- 可见性变更与文案编辑都触发首页缓存 `feed:home:ids` 失效（沿用事件机制，删除已有失效逻辑）。

## 前端设计

- `api/posts.js`：新增 `setPostVisibility(id, visibility)`、`updatePost(id, payload)`。
- 新组件 `components/PostMorePanel.vue`：承载移动 / PC 两种形态、编辑弹窗、删除确认。
- `FeedItem.vue` / `PcFeedCard.vue`：仅 `isMine` 时渲染「⋯」按钮，emit `more`。
- `FeedView.vue`：维护 `morePost` 状态；可见性变更就地更新该条，编辑就地更新标题/简介，删除后从列表移除并保持当前索引不跳（越界时回退到最后一条）。
- `ProfileView.vue`：网格私密角标。

## 边界与决策

1. 删除有二次确认（不可恢复）。
2. 私密作品的既有点赞和评论保留，重新公开后恢复可见。
3. 编辑只改标题和简介，不换封面 / 视频。
4. 删除当前正在播放的作品时，停留在同一位置继续播放下一条；列表空了显示空状态。
5. 私密作品不出现在首页和他人的任何列表中，但作者自己的作品流和个人主页始终可见。

## 验收标准

- 自己的作品：右侧「⋯」可见，三个功能都能用。
- 他人的作品：没有「⋯」。
- 设为私密后：刷新首页看不到；他人主页看不到；作品详情返回「作品不存在」；自己主页有锁角标且能正常播放。
- 重新公开后：恢复出现在首页和他人视野中。
- 编辑文案后：作品流与个人主页立即显示新文案，刷新后仍是新文案。
- 删除后：首页 / 个人主页 / 详情都不再出现，MinIO 对象被清理。
